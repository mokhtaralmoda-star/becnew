نسخة كاملة من ملفات المشروع الحالي والصور والخطوط والاختبارات وإعدادات التشغيل.
النسخة تخص مشروع Lovable الحالي، وليست دمجاً مع المستودع الخارجي.
تم تضمين الصور المحفوظة على Lovable كملفات محلية داخل public/__l5e/assets-v1 للمحافظة على عمل مساراتها.
لا تتضمن مفاتيح سرية أو سجل Git أو مكتبات node_modules أو نواتج البناء؛ تُثبّت المكتبات من ملفات الاعتماد المرفقة.
التشغيل: ثبّت Bun، ثم افتح مجلد المشروع وشغّل:
bun install
bun run dev
عنوان الخادم Socket.IO يضبط وفق .env.example و SOCKET_IO.md.
ربط الخادم وإرسال الطلبات الفعلي ما زالا بانتظار خادمك كما في المشروع الحالي.
